# Online appendix: Measuring Contestability in Digital Markets

Online appendix to *Beyond Market Concentration: Measuring Contestability in Digital Markets* (Zhiyang Cheng, Tracy Xu, Amr Yakout).

Site: https://zycheng114514.github.io/contestability-appendix/

| Page | What it holds |
| --- | --- |
| [Appendix](https://zycheng114514.github.io/contestability-appendix/) (the main page) | The Coding Handbook's content in three parts: Summary, De Jure Scoring and De Facto Scoring |
| [Database](https://zycheng114514.github.io/contestability-appendix/database.html) | A guide to the project database, `data/contestability.db`, with the rows of every table viewable in the page |
| [Coding Handbook](https://zycheng114514.github.io/contestability-appendix/handbook.html) | The Contestability Index Coding Handbook (V4.1, July 2026) in full, with a PDF in `files/` |

On the Appendix page, section numbers, text and tables are as in the Handbook, except that three sentences are left out: the last sentence of the first paragraph of V.A.4, and the two sentences of Section I in which the Handbook refers to itself. The Coding Handbook page has the Handbook with nothing left out.

The pages are generated from the Handbook and the database, so corrections belong there, not in this repository.

The site is kept out of search engines (`noindex`), but anyone with the link can open it.
